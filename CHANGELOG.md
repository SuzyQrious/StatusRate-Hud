# Changelog

## 1.3.2
- Fix startup failure under MelonLoader's invariant-globalization runtime.
- Format decimals using a customized invariant culture instead of creating named cultures.
- Add regression testing in invariant-globalization mode.

## 1.3.1
- Show a live layout preview only while the Status Rate HUD settings tab is selected.
- Allow previewing size and position even when the gameplay HUD is disabled.
- This version inherited the localization startup issue; superseded by 1.3.2.

## 1.3.0
- Add 19-language HUD/settings localization, localized decimal separators and adaptive column widths.
- Prefer the game's font with language-specific OS fallbacks.
- This version had a localization startup issue; superseded by 1.3.2.

## 1.2.0
- Hide the HUD in non-gameplay menus.
- Replace the large background panel with compact text and slim gauges.

## 1.1.0
- Show change per real-world second, refreshed approximately every 0.5 seconds.

## 1.0.0
- Initial version using in-game hourly rates.
